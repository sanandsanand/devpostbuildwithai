Relentless Challenger - App Map

What this is

This is a proof-of-concept AI tutor designed to challenge you on coding and finance. Instead of giving you answers, it pushes back with harder questions to test your true understanding. The app is built with Next.js, Tailwind CSS, and the Vercel AI SDK.

Code Route: Where things happen

  1. The UI & State: src/components/Chat.tsx

    This handles the chat interface, image uploads, and saving your chat history to Local Storage.

  2. The Brain: src/app/api/chat/route.ts

    This is where the magic happens. It takes the messages, enforces the relentless persona using a system prompt, and calls the Gemini API to get a response.

To change this, start here:

  • Want to change the AI's personality? Open src/app/api/chat/route.ts and edit the system prompt string inside the streamText call.
  • Want to change the styling? Open src/components/Chat.tsx and modify the Tailwind classes (like changing background colors or spacing).
  • Want to clear your chat history? Since it's stored in Local Storage, you can open your browser's developer tools (F12) > Application > Local Storage and clear the data, or just use the browser in incognito mode.

A Practice to Reuse

Isolating the unique kernel early: We built the rigid persona (Slice 2) before adding complex features like image uploads. By testing the prompt logic in plain text first, we verified the core risk of the project without getting distracted by UI complexities. Next time you build an AI app, identify its "unique kernel" and prove it works as early as possible.

Running the App

Run npm run dev in your terminal and open http://localhost:3000 in your browser.
